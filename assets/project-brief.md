# 웹사이트 제작 브리프

이 문서를 프로젝트로 복사하고 필요한 항목만 채운다. 예시 사이트의 색·구조·서비스명을 복제하지 않는다. 미확인 값은 공개 콘텐츠에 사용하지 않는다.

## 범위와 현재 환경

- 사업/브랜드:
- 신규 / 확장 / 부분 개선:
- 원하는 사용자 경험과 우선 페이지:
- 현재 코드·콘텐츠·호스팅:
- 유지할 승인 사항:
- 구현·미디어 생성·배포의 승인 범위:
- 필요한 연락처/외부 계정 정보:

## 사업과 근거

- 주 고객·구매 결정자:

- 사용자 경험/실적 근거:
- 공급 범위 밖인 영역:
- 공개 가능한 사례·사진·고객 자료:
- 계획 예시·가상 시나리오와 미확인 항목:
